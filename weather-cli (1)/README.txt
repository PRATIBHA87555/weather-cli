Weather CLI
===========
Needs Python 3.8+ and an internet connection. No API key required (uses Open-Meteo).

Windows quick start:  double-click run.bat

Manual:
  pip install -r requirements.txt
  python weather.py              (interactive: type city names)
  python weather.py Agra         (show one city and exit)
  python weather.py "New York" -u imperial

In interactive mode:  u = switch C/F and mph/kmh,  q = quit
For the best look use Windows Terminal (or any modern terminal).
